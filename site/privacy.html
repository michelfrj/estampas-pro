Privacidade do Estampas Pro

As artes são processadas localmente no navegador. A imagem que você abre, os previews e os arquivos gerados para download não precisam ser enviados ao servidor para que o editor funcione.

Sua arte fica com você

Enquanto você prepara uma estampa, a imagem e os resultados do processamento permanecem no seu dispositivo. Isso inclui os pixels da arte, as visualizações temporárias, as separações geradas e os arquivos preparados para download.

O Estampas Pro não mantém uma cópia dessas imagens no serviço de conta.

Dados da sua conta

Para permitir login, recuperação de senha e sincronização entre sessões, podem ser armazenados seu identificador de conta, e-mail, nome de exibição e informações necessárias ao funcionamento seguro da autenticação.

Histórico de exportações

Quando você conclui uma exportação, o histórico pode registrar informações úteis para consultar o trabalho depois, como nome do arquivo, data, dimensões, resolução, modo de processamento e configurações usadas.

O histórico não guarda a imagem, uma miniatura da arte nem o arquivo exportado.

Presets

Os presets guardam o nome escolhido e as configurações necessárias para reutilizar um ajuste. Informações detectadas especificamente a partir de uma determinada imagem não são tratadas como parte permanente do preset.

Seus dados não são compartilhados com outras contas

Os dados sincronizados são associados à conta que os criou. Os controles de acesso do serviço são configurados para impedir que uma conta consulte ou altere os registros de outra.

Exclusão

Na área da conta você pode excluir histórico, presets e, quando desejar, a própria conta. A exclusão definitiva não permite recuperar os dados removidos posteriormente.

Como as artes não são armazenadas no serviço de conta, não existe uma cópia delas no servidor para ser apagada.

Serviços utilizados

O Estampas Pro pode utilizar Supabase para autenticação e sincronização dos dados da conta, Google como opção de login e Cloudflare Turnstile para proteção contra robôs e tentativas de abuso.

Nosso compromisso

Coletamos apenas as informações necessárias para oferecer as funções descritas nesta política. Se o conjunto de dados sincronizados mudar de forma relevante, esta página será atualizada para explicar a alteração.
